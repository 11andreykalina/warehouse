# Склад форменного имущества

Адаптивный MVP-интерфейс для просмотра каталога форменного имущества и отправки заявок на получение. Это прототип на mock-данных, а не подключённая к складу система: сервер, реальные остатки и учёт выдачи пока не настроены.

## Возможности

- Главная страница с категориями и примерами позиций из каталога.
- Общий каталог с фильтрами по категории, сезону, службе и полу; дополнительный фильтр подбирает позиции по демо-профилю, но не скрывает остальные товары.
- Готовые комплекты с фильтрами по сезону, службе и полу; состав с переходами к товарам и добавление комплекта после выбора размера каждой позиции.
- Страница позиции с выбором одного из указанных размеров.
- Заявка с изменением количества; после отправки она сохраняется в истории в этом браузере. При подтверждении получения указываются сроки носки, а выданные позиции автоматически добавляются в гардероб.
- Гардероб с нормативным сроком носки и обратным отсчётом в днях; по истечении срока вещь автоматически переносится в архив с переходом в каталог для новой заявки. Можно внести ранее полученную вещь, при этом срок определяется нормой и не редактируется пользователем.
- Корзина, заявки и гардероб используют общее состояние Redux Toolkit и сохраняются в `localStorage`; изменения синхронизируются между вкладками этого браузера.
- Страницы загружаются по требованию, чтобы посетитель не скачивал код всех разделов при первом открытии.
- Демо-профиль и экран демонстрационного входа.
- Переключение светлой и тёмной тем с сохранением выбора в браузере.
- Адаптивная навигация и понятные пустые состояния для разделов, которые пока не подключены к серверу.

## Структура

Код организован по слоям Feature-Sliced Design: `app`, `pages`, `widgets`, `features`, `entities`, `shared`. Каждый срез в `entities`, `features`, `widgets` и `pages` предоставляет публичный API через свой `index.ts`; потребители не импортируют внутренние файлы другого среза. Данные каталога — демонстрационные; заявки и гардероб хранятся в `localStorage` текущего браузера. Состояние демо-входа относится к feature `auth-by-badge`. Правила направления зависимостей и импорта через публичные API проверяются командой `npm run check:fsd`.

Изображения сгруппированы в `public/images` по назначению: `products` для товарных позиций, `outfits` для примеров комплектов и `branding` для эмблемы приложения. Пример летнего повседневного комплекта использует `images/outfits/summer-daily.jpeg`; для товарных позиций без фотографии интерфейс показывает заглушку. Учёт выдачи и сроков носки демонстрационный: данные не отправляются на сервер и не заменяют официальное оформление вещевого довольствия.

## Нормы вещевого обеспечения

Каталог различает **нормы снабжения** и **правила ношения**. Базовые предметы и сроки снабжения задаёт Постановление Правительства РФ от 13.10.2011 № 835: обычная норма выбирается по полу и категории состава; для отдельных служебных обязанностей предусмотрены дополнительные нормы № 10 (надзор за дорожным движением) и № 17 (строевые подразделения ППС и другие прямо перечисленные подразделения). Норма № 17 не применяется к указанным в её примечании подразделениям в местностях с жарким климатом и к специальному полку полиции им. А. А. Кадырова. Следствие использует базовую норму по полу и категории состава; отдельной нормы для следственных подразделений в перечне нет.

Приказ МВД России от 17.11.2020 № 777 регулирует правила ношения формы, а не нормы снабжения. Постановление Правительства РФ от 27.01.2024 № 71 приостанавливает до 01.07.2028 выдачу некоторых отдельных предметов; при добавлении таких позиций в каталог их нельзя помечать как доступные без соответствующего предупреждения.

В демонстрационных данных указаны только отдельные проверенные позиции из норм № 2, 4, 10 и 17. Позиции нормы № 10 доступны в профильной подборке при выборе надзора за дорожным движением либо службы на мотоцикле; позиции нормы № 17 — для строевого подразделения ППС с учётом исключений. Для летнего кепи по нормам № 2 и 4 учтены специальные сроки: 3 года по общему правилу, 2 года при наружной службе (кроме надзора за дорожным движением) и 1 год при таком надзоре. Примечания норм, климат, конкретная должность и фактическая выдача могут влиять на право и срок. Перед применением в реальном учёте данные необходимо сверить с официально опубликованной актуальной редакцией и карточкой сотрудника.

Ссылки на сводные тексты: [Постановление № 835](https://www.consultant.ru/document/cons_doc_LAW_120512/), [норма № 4 для женщин](https://www.consultant.ru/document/cons_doc_LAW_120512/dbc950f086ee8be11d2765eb00f79fc477ebd05c/), [норма № 10 для надзора за дорожным движением](https://www.consultant.ru/document/cons_doc_LAW_120512/3d530ceba88682645e5125e9ce0ed15c567a8728/), [норма № 17 для строевых подразделений ППС](https://www.consultant.ru/document/cons_doc_LAW_120512/86e074860f84d80bc03e384a985119d8621a7b48/), [Постановление № 71](https://www.consultant.ru/document/cons_doc_LAW_468538/), [Приказ МВД № 777](https://docs.cntd.ru/document/573174924).
